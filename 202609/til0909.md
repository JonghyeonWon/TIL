## 1. hover  

- `:hover`: 마우스를 요소 위에 올렸을 때의 스타일을 변경할 수 있는 가상 클래스  
- `transition`: 스타일 변화가 즉시 일어나지 않고 지정한 시간 동안 부드럽게 이어지게 됨  

- `transition`은 변화가 시작되는 곳(`:hover`)에 작성하게 되면 마우스를 올릴 때만 부드러워지므로 평소 상태에 써야 올릴 때와 뗄 때 양방향 모두 부드럽게 변화함

## 2. input, id / name  

### 2-1 input 타입  

- `text`: 어떤 글자든 입력이 가능  
- `email`: 모바일에서 @ 키보드가 뜨고, 형식이 틀렸을 때 브라우저가 알림  
- `date`: 달력 선택 UI가 자동으로 나타남  (2000-01-01 형식)  

### 2-2 id와 name  

- `id`: 문서 안에서 이 요소 하나를 특정하는 역할  
    - CSS 선택자, JavaScript, <label>의 for 속성에서 사용  
    - <label>의 `for` 속성에 id를 적어두면 라벨 글자를 클릭해도 입력창이 활성화되며, 화면을 볼 수 없는 사용자의 웹 접근성도 향상  

- `name`: 폼 데이터의 이름표 역할
    - FormData에서의 데이터 수집, 서버 전송

- id만 넣고 name을 빠뜨리면 화면에는 잘 보이지만 데이터를 가져올 수 없게 됨

## 3. JavaScript 기초  

### 3-1 const와 let  

- `const`: 한 번 할당하면 값을 재할당할 수 없는 변수  
- `let`: 값이 변경되어야 할 때 사용되는 블록 스코프 변수  

- `const`는 가리키는 대상의 변경이 불가능한 것이므로 객체/배열 내부의 요소는 변경 가능  

---

### 3-2 자료형, 템플릿 리터럴  

- `null`: 값이 없음을 개발자가 명시적으로 알리는 상태  
- `undefined`: 아직 아무 값도 넣지 않은 상태  

- 백틱 문자열: 백틱으로 감싼 문자열에서는 `${}` 형태로 표현식을 직관적으로 삽입 가능  
    - 줄바꿈 또한 그대로 유지되므로 가독성이 뛰어남  

---

### 3-3 연산자  

- `===`, `!==`: 값과 자료형까지 같이 비교
    - `==`은 자료형을 동일하게 맞춰놓은 후 비교하므로 `1 == "1"`이 true인 결과를 반환  

- 거짓으로 취급되는 값: `false`, `0`, `""(빈 문자열)`, `null`, `undefined`, `NaN`  
- 참으로 취급되는 값: 거짓으로 취급되는 값 이외 모든 것  
    - `[](빈 배열)`, `{}(빈 객체)` 또한 참으로 여겨짐  

- `||`: 왼쪽 값이 `falsy`일 때 오른쪽의 기본값으로 변경됨  
- `??`: 왼쪽 값이 `null`, `undefined`일 때만 오른쪽의 기본값으로 변경   
- `?.`: 값이 없으면 오류 대신 `undefined`를 반환  

---

### 3-4 반복문  

- `forEach`: 배열 전체를 순회할 때 사용  
```javascript
students.forEach((student) => console.log(student.name));
```

- `for..of`: 중간에 `break`로 멈춰야 할 때  
```javascript
for (const student of students) {
    if (student.id === 7) break;
    console.log(student.name);
}
```

- `for문`: 인덱스가 필요할 때  
```javascript
for (let i = 0; i < students.length; i++) {
    console.log(i, students[i].name);
}
```

### 3-5 함수  

- 함수 선언: `function` 키워드로 선언하며 `Hoisting(호이스팅)`을 지원하므로 코드 아래쪽에 작성해도 위에서 해당 함수를 호출 가능  

- `function` 대신 `=>`를 사용하는 간결한 함수 표기법  

```javascript
function (response) { return response.json(); }   // ① 전통적인 표기
(response) => { return response.json(); }         // ② 화살표 함수
(response) => response.json()                     // ③ 중괄호와 return 생략
```

### 3-6 객체  

- `student.name` 같이 점으로 속성에 접근 가능  
- 중첩 객체는 `student.detailRequest.address` 같이 연속으로 접근  
- `undefined` 상태의 속성에 점을 찍으면 오류가 발생하므로 삼항 연산자를 이용한 방어 코드 필요  

- `JSON.stringify`: 객체 -> 문자열로 변경  
- `JSON.parse`: 문자열 -> 객체로 변경
