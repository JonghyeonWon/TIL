## 1. useCallback

- 함수형 컴포넌트는 렌더링될 때마다 내부의 모든 코드가 다시 실행되므로, 함수 선언문 역시 매번 새로운 메모리 주소를 가진 새로운 함수 객체로 다시 생성됨  

- 의존성 배열에 지정된 값이 바뀌지 않는 한, 이전 렌더링 때 만들어둔 함수 인스턴스를 그대로 재사용  

- 주로 자식 컴포넌트에 함수를 `props`로 전달할 때, 불필요한 함수 재생성으로 인해 자식 컴포넌트가 연쇄적으로 리렌더링되는 성능 저하를 방지하기 위해 사용

## 2. Single Page Application(SPA)과 React Router  

- 멀티 페이지 웹사이트는 페이지를 이동할 때마다 서버에 새로운 HTML을 요청하여 전체 화면이 깜빡이지만, React 같은 SPA(Single Page Application)는 하나의 HTML 위에서 JavaScript를 통해 **주소(URL)에 따라 필요한 컴포넌트만 바꿔 끼워** 부드러운 화면 전환을 제공함  

### 주요 라우터 컴포넌트의 역할  

- `<BrowserRouter>`: 브라우저의 현재 주소와 React 앱을 동기화해 주는 라우터 **최상위** 컨테이너  

- `<Routes>` & `<Route>`: 현재 브라우저의 URL 경로와 매칭되는 컴포넌트를 찾아 화면에 렌더링하는 조건부 라우팅 제어  

- `<Link>` & `<NavLink>`: `<a>` 태그를 그대로 쓰면 브라우저가 페이지 전체를 새로 내려받으면서 가지고 있던 state가 모두 사라지므로, 페이지를 새로고침하지 않고 브라우저 주소만 변경하여 SPA의 특성을 유지하면서 페이지 이동을 구현

## 3. useEffect의 정리 함수(Cleanup)  

- `useEffect` 내부에서 리턴하는 함수는 컴포넌트가 소멸할 때(`componentWillUnmount`) 또는 다음 이펙트가 실행되기 직전에 호출됨  

- 이 정리 함수 내부에 `clearTimeout`이나 `clearInterval`을 배치하여, 예약된 타이머 작업을 안전하게 취소하고 리소스를 해제
