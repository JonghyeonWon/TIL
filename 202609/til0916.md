## 1. Ref  

- React는 DOM을 직접 조작하지 않고 `State` 값으로만 화면을 제어해야 함  
- 상태 값으로 표현할 수 없는 **예외적인 동작**에 대해서만 실제 `DOM`에 접근  

- 값으로 표현할 수 없는 동작  

    1. 특정 요소로 스크롤  
    2. 동영상 재생 / 정지  
    3. 입력 칸에 대한 포커스 제어  
    4. 요소의 실제 크기 제어  

- 클래스형 컴포넌트: `ref={(ref) => this.myUsername = ref}`를 사용하여 DOM 요소를 변수에 담아서 관리  

- 함수형 컴포넌트: `const myRef = useRef(null);` 형태로 선언한 뒤 태그의 `ref={myRef}` 속성과 연결하여 `myRef.current`로 실제 DOM에 접근  

### state와 ref  

| 구분 | State (`useState`) | Ref (`useRef`) |
| :--- | :--- | :--- |
| **바뀌면** | 화면을 **다시 그린다**  | 화면을 **다시 그리지 않는다** |
| **값 읽기** | 이번에 그려질 때의 값 (클로저에 갇힌 시점의 값) | 언제나 **최신 값** (`ref.current`) |
| **용도** | 화면에 실시간으로 반영되어야 하는 값 | DOM 요소 접근, 타이머 ID 등 화면과 무관한 값 |
| **바꾸는 법** | 전용 함수 사용 (`setValue(새 값)`) | 직접 수정 가능 (`ref.current = 새 값`) |

## 2. useEffect()  

- 컴포넌트는 여러 번 실행되는데, 이 안에서 서버를 호출하거나 타이머를 걸면 컴포넌트가 실행될 때마다 반복되는 문제가 발생  

- `useEffect`는 화면을 다 그린 뒤에 작성한 일을 하라는 의미를 담고 있음  

- 함수 컴포넌트에도 생명주기가 존재하지만, `componentDidMount` 같은 이름은 존재하지 않음  -> 메서드 이름을 붙이는 대신 `Hook`을 사용  

- 클래스에서 `componentDidMount`, `componentDidUpdate`, `componentWillUnmount` 세 메서드에 나눠서 적던 것을 `useEffect` 하나로 작성 가능해짐  

1. `useEffect(fn, [])`: `componentDidMount` 대체 / 처음 화면에 나타날 때 한 번 실행됨  
2. `useEffect(fn, [a, b])`: `componentDindMount` + `componentDidupdate` 대체 / 지정한 value 값이 바뀔 때 마다 실행됨  
3. `useEffect(fn)`: `componentDidMount` + `componentDidUpdate` 대체 / 화면을 다시 그릴 때마다 실행  
4. `useEffect 함수에서 return하는 함수`: `componentWillUnmount` 대체 / **꺼야 하는 것들**을 처리

## 3. Memo / Callback

### 1. memo

- 부모 컴포넌트가 리렌더링되면, 그 아래에 있는 자식 컴포넌트들도 기본적으로 전부 다시 그려지게 됨. 이때 자식 컴포넌트의 내용이 바뀌지 않았다면 렌더링을 건너뛰어 성능을 최적화할 수 있음  

- 컴포넌트의 렌더링 결과물을 기억해 두었다가, 전달받은 Props가 이전과 같다면 Virtual DOM을 새로 만들지 않고 이전에 그려둔 결과를 재사용  

### 2. Callback

- 함수형 컴포넌트는 실행될 때마다 내부에 선언된 함수들이 새로운 참조 주소를 가진 함수로 다시 생성됨. 이 때문에 함수를 props로 받는 자식 컴포넌트는 `React.memo`를 써도 props가 바뀌었다고 오인하여 리렌더링됨  

- 의존성 배열에 명시된 값이 바뀌지 않는 한, 이전에 만든 함수 인스턴스를 메모리에 캐싱해 두고 그대로 재사용  

- 자식 컴포넌트에 함수를 props로 넘길 때는 반드시 `useCallback`을 함께 사용하여 함수의 주소값 변동을 막아야 `React.memo`가 온전하게 동작  

- `memo`는 계산 결과를, `callback`은 함수 자체를 기억해 둠
