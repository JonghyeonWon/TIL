## 1. React  

- `React`: 값을 받아서 화면을 출력해주는 JavaScript 라이브러리  
- `React`는 화면 그리기 외의 기능은 포함하지 않기 때문에, 프레임워크가 아니라 라이브러리로 분류됨  

- `ECMAScript`는 명령형 방식으로, `document.getElementById`로 요소를 찾고 그 객체의 속성을 직접 수정했었지만, `React`는 선언형 방식으로, 화면이 어떻게 생겼는지를 나타내는 상태 값을 선언하기만 하면 되는 방식  

- 데이터는 `부모 -> 자식`으로만 흐르며, 자식이 값을 바꾸고 싶을 때에는 부모가 내려준 함수를 통해서 요청해야함  

---

## 2. virtual DOM  

- 값이 바뀔 때마다 실제 DOM을 바로 고치지 않고 메모리에 JavaScript 객체로 된 가상의 DOM을 새로 작성  

- 동작 3단계  

    1. 렌더링: 값이 바뀌면 새로운 가상 DOM 객체 생성  
    2. 재조정: 바뀌기 전 가상 DOM과 새로운 가상 DOM을 비교하여 달라진 부분을 확인  
    3. 커밋: 실제 DOM을 변경하는 일은 비싸기 때문에, 달라진 부분만 실제 DOM에 반영  

---

## 3. Component  

- `Component`: `React`에서 컴포넌트는 **화면을 돌려주는 함수**  

- 컴포넌트 정의 예시  
```javascript
function MessageBox() {
    return <span className="error-message">저장되었습니다.</span>;
}
 
export default MessageBox;
```

- 컴포넌트 사용 예시
```javascript
<MessageBox />
```

- 컴포넌트 작성 규칙

    1. 이름은 **대문자**로 시작  
    2. 리턴하는 태그는 반드시 **하나**여야 함  
    3. 같은 입력이 들어오면 같은 화면이 출력되어야 함

## 4. JSX(JavaScript XML)  

- JavaScript 안에서 HTML 구조를 편하게 작성할 수 있는 문법  
- JSX 자체는 브라우저가 이해할 수 없으므로 `Vite` 등의 빌드 도구가 `createElement` 형태의 JS 코드로 변환함  
- `.jsx` 형태의 확장자는 번역이 필요하다는 의미를 내포  

- JSX 없는 객체 생성
```javascript
React.createElement(
    "tr",
    { key: student.id },
    React.createElement("td", null, student.name),
    React.createElement("td", null, student.studentNumber),
    React.createElement("td", null, student.detail?.address ?? "-")
);
```

- JSX를 사용한 객체 생성
```javascript
<tr key={student.id}>
    <td>{student.name}</td>
    <td>{student.studentNumber}</td>
    <td>{student.detail?.address ?? "-"}</td>
</tr>
```

- 주요 JSX 문법 규칙

    1. class 대신 `className` 사용  
    2. for 대신 `htmlFor` 사용  
    3. HTML 속성은 `CamelCase` 사용  
    4. 스타일은 문자열이 아닌 객체로 전달 (예: `style={{ color: "red" }}`)
    5. 닫는 태그가 없는 요소(예: <br>)도 반드시 닫아주어야 함 (<br />)  
    6. 중괄호 {} 안에는 변수, 함수 호출, 삼항 연산자 등 **값**을 반환하는 JavaScript 코드를 작성

## 5. Props / State  

- `Props`: 부모가 전달하는 값으로, 읽기 전용이므로 변경이 불가  
- `State`: 자식 컴포넌트가 스스로 가지는 값으로, `SetState`를 통해 변경이 가능  
- state가 바뀌면 React가 그 컴포넌트를 다시 실행하여 화면을 새로 그리므로, 화면에 영향을 주는 값은 `State`로 지정  

---

## 6. Event Handling in React  

- addEventHandler 대신 `onClick`, `onChange`, `onSubmit` 사용  
- 문자열이 아니라 **함수**를 넘김  

```javascript
// 인자가 필요 없는 경우
<button onClick={handleClick}>확인</button>
 
// 인자가 필요한 경우 화살표 함수로 감싸서 호출
<button onClick={() => onDelete(id)}>삭제</button>
 
// 이렇게 인자를 전달하면 함수가 즉시 실행되고, 
// 만약 함수가 state를 변경한다면 함수가 무한히 반복
<button onClick={onDelete(id)}>삭제</button>
```

## 7. React Hook  

- 과거 React는 state를 가지려면 **클래스**로 작성했어야 함  

- 클래스 예시 코드  
```javascript
class StudentList extends React.Component {
    constructor(props) {
        super(props);
        this.state = { students: [], loading: false };
        this.handleClick = this.handleClick.bind(this);  
    }
 
    componentDidMount() {          // 화면에 붙은 뒤
        this.loadStudents();
    }
 
    componentDidUpdate(prevProps) { // 갱신된 뒤
        if (prevProps.id !== this.props.id) this.loadStudents();
    }
 
    componentWillUnmount() {        // 사라지기 전
        clearTimeout(this.timer);
    }
 
    handleClick() { this.setState({ loading: true }); }
 
    render() {
        return <div>{this.state.students.length}명</div>;
    }
}
```

- 각 메서드들의 이름이 정해져 있고, 이름이 다르면 작동하지 않음  
- 컴포넌트는 `Mounting` -> `Updating` -> `Unmounting`의 생명주기를 가짐  
- `render()`로 화면 반환  

- 컴포넌트가 `state와 생명주기`를 다룰 수 있도록 `Hook`이 등장했고, 이름이 모두 `use`로 시작함  

- Hook 예시 코드  
```javascript
// 위 클래스 컴포넌트를 Hooks 로
function StudentList({ id }) {
    const [students, setStudents] = useState([]);
    const [loading, setLoading] = useState(false);
 
    useEffect(() => {
        loadStudents();
    }, [id]);          // 처음 + id 가 바뀔 때 (두 생명주기가 한자리에)
 
    return <div>{students.length}명</div>;
}
```

- `this`가 사라지고 `return`으로 화면을 반환하는 등 코드 또한 더 간결해짐

## 8. useState 

- 함수형 컴포넌트 안에서 상태를 관리하기 위해 사용하는 `Hook`  
- **배열 구조 분해 할당**을 통해 **현재 값**과 **Setter**를 반환받음  

```javascript
  const [count, setCount] = useState(0); // 초기값 0 설정
```

- state는 직접 대입해서 바꿀 수 없고, 반드시 `setCount`와 같은 Setter 함수를 통해서만 변경해야 React가 변화를 감지하고 화면을 다시 그려줄 수 있음
