## 1. ECMA Script  

- `ECMA Script`: 표준 규경으로 정의된 `JavaScript` 언어의 핵심 문법 규격  
- `JavaScript`: `ECMA Script` 표준 문법 + 실행 환경의 기능    
- 2009년 `ES5`까지 JavaScript는 `var`, `function`으로만 쓰는 언어였지만, 2015년 `ES6`에서 다양한 기능이 들어오면서 언어의 모습이 완전히 달라짐  
- 보통 `ES5`인가, `ES6+`인가를 구분함 -> 불특정 다수를 대상으로 하는 서비스는 **브라우저 호환성**을 고려해야함

## 2. 빌드 도구  

### 2-1. 빌드 도구가 필요한 이유  

- **호환성 문제**: 최신 문법으로 쓴 코드는 구버전 브라우저에서 잘 돌아가지 않음  
- **파일 관리의 어려움**: `js` 파일이 많아지면 `<script>` 태그를 이용하여 일일이 등록해야함  
- **실수 방지**: 코드 실행 전 오타, 미사용 변수 등 정적 분석이 필요  

### 2-2. 주요 도구 종류

- **트랜스파일러(transpiler)**: 최신 문법을 구 버전의 문법으로 변환(`Babel`, `SWC`)
- **번들러(Bundler)**: 여러 JS/CSS.. 파일들을 하나로 합치고 최적화(`Webpack`, `Rollup`)  
- **정적 분석 도구(Static Analyzer)**: 코드 실행 없이 문법 오류 및 스타일 검사(`ESLint`)  

### 2-3. Node.js / npm  

- **Node.js**: 브라우저 밖(내 컴퓨터)에서 JavaScript를 실행할 수 있게 해주는 환경  

    - `Babel`, `Vite`, `ESLint` 같은 빌드 도구들도 모두 `Node.js` 환경 위에서 동작함  

- **npm (Node Package Manager)**: 오픈소스 라이브러리를 내려받고 실행 스크립트를 관리하는 도구  
- **`package.json`**: 프로젝트 정보, 의존성 라이브러리 목록, 실행 스크립트를 정의하는 설정 파일  
- **`node_modules`**: 실제로 설치된 라이브러리 파일들이 들어가는 폴더  

    - 용량이 크고 `package.json`으로 언제든 재복원할 수 있으므로 git 관리 대상에서 제외(`.gitignore`)

### 2-4. Vite 

- `Vite`: 오늘날 가장 널리 쓰이는 매우 빠른 프론트엔드 빌드 도구  
    - 기존의 `CRA(Create React App)`을 대체  

- 소스 코드를 수정하면 변경 부분만 즉시 반영되는 `HMR(Hot Module Replacement)` 기능으로 빠른 개발 서버 제공  

- 내부적으로 `Rollup` 번들러를 사용해 배포용 파일 생성

## 3. var, let, const  

### 3-1. var의 문제점  

- 함수 스코프: 블록({ })을 무시하여 if문이나 for문 내부에서 선언한 변수가 외부에서도 접근 가능함  
- 중복 선언 허용: 동일한 변수 이름을 재선언해도 오류 없이 값이 덮어씌워져 의도치 않은 버그 발생 가능  
- 호이스팅 시 undefined로 초기화: 선언문 이전에 변수를 참조해도 에러가 나지 않고 `undefined`를 반환    

### 3-2. let과 const  

- 공통점: 블록 스코프를 따르며, 동일 스코프 내 중복 선언 불가, 선언 전 접근 불가  
- `let`: 재할당이 가능한 변수 선언 키워드  
- `const`: 재할당이 불가능한 상수 선언 키워드  
    - `const`로 선언된 객체나 배열의 참조(메모리 주소)는 고정되지만, 내부 속성 추가·수정·삭제는 가능    

- 변수 선언 예시

```javascript
console.log(x);     // undefined  
var x = 10;

console.log(y);     // ReferenceError: Cannot access 'y' before initialization
let y = 10;
// function 선언
loadStudents();                       // 정상 동작
function loadStudents() { }
// 함수 표현식
loadStudents2();                      // ReferenceError
const loadStudents2 = () => { };
```

## 4. 화살표 함수와 this  

### 4-1. this  

- function 선언의 this: 함수가 어디서, 어떻게 호출되었느냐에 따라 this가 결정됨  
    - 객체의 메서드로 호출되면 해당 객체를 가르키고, 콜백 함수나 일반 함수로 호출되면 `window`를 가르킴  

- 화살표 함수의 this: 화살표 함수는 자체적인 this를 가지지 않고, 함수가 선언된 위치의 상위 스코프의 this를 그대로 받아와 사용  

- `this` 작동 차이 코드 예시
```javascript
const timer = {
  name: '스톱워치',
  // 1. 일반 함수를 콜백으로 사용한 경우 
  startNormal: function() {
    setTimeout(function() {
      // setTimeout 내부의 일반 함수는 전역(window/undefined)에서 호출됨
      console.log(this.name); // undefined (또는 에러)
    }, 1000);
  },
  // 2. 화살표 함수를 콜백으로 사용한 경우 (this 유지)
  startArrow: function() {
    setTimeout(() => {
      // 상위 스코프인 startArrow의 this(timer 객체)를 그대로 참조함
      console.log(this.name); // '스톱워치'
    }, 1000);
  }
};
```

## 5. 구조 분해 할당  

### 5-1. 객체 분해 할당  

- 객체의 속성을 꺼내서 동명의 변수로 즉시 선언 및 할당하는 방법  
- `기존속성: 새변수명` 형태로 추출하여 변수 이름을 바꿔 받을 수 있음  
- 값이 `undefined`일 경우 적용될 기본값을 설정할 수 있음  
- 중첩 객체 분해: 객체 내부의 객체 속성까지 깊게 들어가서 추출 가능  

- 객체 분해 예시
```javascript
const user = {
    name: '둘리',
    age: 30,
    phone: {
        home: '1234',
        mobile: '4566'
    }
};
const { name, age, phone } = user;
console.log(name);     // 둘리
console.log(age);      // 30
console.log(phone);    // { home: '1234', mobile: '4566' }
// 두 번에 나눠서 중첩 객체 할당 
const { name, age, phone } = user;
const { home, mobile } = phone;
// 한 번에
const { name, age, phone: { home, mobile } } = user;
console.log(home);     // 1234
console.log(mobile);   // 4566

const { name: userName } = user;        // name 을 userName 이라는 이름으로 받기
const { address = '미입력' } = user;     // 값이 없으면(undefined) '미입력'
```

### 5-2. 배열 분해 할당  

- 배열의 요소를 순서에 따라 변수에 할당 가능  
- 불필요한 요소는 쉼표(,)로 건너뛸 수 있음  

```javascript
const colors = ['red', 'green', 'blue'];
// 순서대로 할당 및 건너뛰기
const [first, , third] = colors;
console.log(first, third); // 'red', 'blue'
// 두 변수의 값 교환 (Swap)
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b); // 2, 1
```

### 5-3. 메서드 분해시의 this 유실  

- 객체 내의 메서드를 분해 시, 호출 주체인 객체를 잃어버림  
- `bind()`를 통해 `this`를 고정하거나, `this`를 쓰지 않도록 설계 필요  

```javascript
const obj = {
    names: 'React',
    greet() {
        return this.names;
    }
};
// (1) bind() 
const boundGreet = obj.greet.bind(obj);
console.log(boundGreet());             // 'React'
// (2) this 대신 객체 이름을 직접 작성
const obj2 = {
    names: 'React',
    greet2: () => obj2.names
};
const { greet2 } = obj2;
console.log(greet2());                 // 'React'
```

## 6. ES6+ 문법  

### 6-1. 전개 구문  

- 점 3개를 값 앞에 붙여 배열이나 객체의 요소를 낱개로 펼쳐서 복사하거나 합칠 때 사용  
- 얕은 복사(Shallow Copy)를 수행하므로 객체 불변성 유지에 활용  

```javascript
const arr1 = [1, 2];
const arr2 = [3, 4];
const combinedArr = [...arr1, ...arr2]; // [1, 2, 3, 4]
```

- 뒤에 오는 값이 앞의 값을 덮어쓴다는 규칙이 존재  

```javascript
const student = { name: '홍길동', score: 80 };
const updatedStudent = { ...student, score: 95, grade: 'A' }; 
// { name: '홍길동', score: 95, grade: 'A' }
```

### 6-2. 나머지 구문  

- 점 3개를 값을 받아야 하는 자리에 사용하면 전개와 반대로 낱개의 값들을 하나로 통합  
- 앞의 것을 따로 받고 나머지를 모을 때에는 나머지 매개변수(...)가 반드시 마지막에 위치해야함  

```javascript
function sum(...numbers) {
    console.log(numbers);
    return numbers.reduce((acc, n) => acc + n);
}
console.log(sum(1, 2, 3));          // 6
console.log(sum(1, 2, 3, 4, 5));    // 15

// 앞의 것만 따로 받고 나머지를 모으기
function log(level, ...messages) {
    console.log(level, messages);      // "INFO"  ["a", "b"]
}
log("INFO", "a", "b");
```

### 6-3. 기본 매개변수  

- 함수 호출 시 전달된 인자가 생략되었거나 undefined일 경우 지정된 기본값이 설정됨  
- null, 0, ""(빈 문자열), false 등은 인자로 전달된 값으로 인정하여 기본값이 적용되지 않음  

```javascript
function greet(name = '손님', age = 20) {
  console.log(`${name}님 (${age}세)`);
}

greet();                // '손님님 (20세)'
greet('철수', undefined); // '철수님 (20세)'
greet('영희', null);      // '영희님 (null세)' <- null은 undefined가 아니므로 기본값 미적용
```

### 6-4. 단축 속성명 / 계산된 속성명  

- **단축 속성명**: 객체를 생성할 때 Key 이름과 표기할 변수 이름이 동일하다면 축약 표현 가능  
- **계산된 속성명**: 객체 리터럴 내부에서 **대괄호**를 사용해 동적으로 Key 이름을 정의 가능  

```javascript
const name = '홍길동';
const studentNumber = '20241234';
// 변수 이름과 속성 이름이 같으면 한 번만 작성
const student = { name, studentNumber };
// { name: '홍길동', studentNumber: '20241234' } 

// 속성 이름을 변수로 정하기 — 대괄호 사용
const key = 'email';
const obj = { [key]: 'a@b.com' };   // { email: 'a@b.com' }
```
