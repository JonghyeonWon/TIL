## 1. HTML 문서의 뼈대와 CSS 연결  

### 1.1 HTML 기본 구조

- `<!doctype html>`: 브라우저가 문서를 해석할 때 최신 HTML5로 작성되었음을 알림  
- `<head>`: 화면에 보이지 않는 메타 데이터  

    - `<meta charset="UTF-8">`: 한글이 깨지지 않도록 문자 세트를 정의  
    - `<link rel="stylesheet">`: 외부의 `CSS` 파일을 호출  

- `<body>`: 실제로 화면에 보이는 내용  

### 1.2 박스 모델  

- HTML의 모든 요소는 사각형 형태의 박스 구조이며, `Content` -> `Padding` -> `Border` -> `Margin` 순서로 구성되어 있음  

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;   
}
 
body {
    font-family: sans-serif;
    background-color: #f4f4f4;
}
```

- `box-sizing`을 `border-box`로 적용하면 지정한 크기 내부에 `padding`, `border`가 포함되어 계산  

- `box-sizing`을 `content-box`로 적용하면 지정한 크기보다 실제 상자 크기가 커질 수 있음  

- `*` 는 모든 HTML 요소를 선택하는 전체 선택자로, `*`을 사용하여 모든 요소에 대해 3가지 옵션을 기본적으로 적용 중

## 2. Flexbox  

- `block`: 내용이 짧아도 가로 한 줄을 통째로 차지함  
- `inline`: 내용의 크기만큼만 차지하고, 옆의 요소와 나란히 이어짐 
- `inline-block`: `inline`처럼 옆으로 나란히 놓이면서, `block`처럼 크기와 여백을 마음대로 지정 가능  

- `<span>`은 인라인 성질을 지니고 있으므로 그냥 사용하면 한 줄로 나란히 출력됨  

```html
<header class="header">
    <h1>KIM CODING</h1>
    <nav>
        <span>Home</span>
        <span>About</span>
        <span>Contact</span>
    </nav>
</header>

```

```css
.header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 20px 50px;
    background-color: #333;
    color: white;
}
```

- `display: flex`: 부모 요소인 `header` 클래스에 지정하여 자식 요소들을 가로/세로 방향으로 나란히 정렬  

    - `flex`는 기본적으로는 가로 방향으로 배치  
    - `flex-direction`으로 축 방향 설정 가능  

- `justify-content(주축 정렬)`: 진행 방향 기준 정렬 방식 정의  
- `align-items(교차축 정렬)`: 주축과 수직인 교차축 방향 기준 정렬 방식 정의

## 3. flex 옵션  

### 3.1 flex-direction

- ``row``: 자식 요소들을 왼쪽에서 오른쪽으로 가로 배치  
- ``row-reverse``: 자식 요소들을 오른쪽에서 왼쪽으로 가로 역순 배치  
- ``column``: 자식 요소들을 위에서 아래로 세로 배치 (주축이 세로로 변경됨)  
- ``column-reverse``: 자식 요소들을 아래에서 위로 세로 역순 배치  

### 3.2 justify-content

- ``flex-start``: 주축의 시작점에 요소들을 정렬  
- ``center``: 주축의 중앙에 요소들을 정렬  
- ``flex-end``: 주축의 끝점에 요소들을 정렬  
- ``space-between``: 첫 요소는 시작점, 마지막 요소는 끝점에 붙이고 요소 사이 간격을 균등 분배  
- ``space-around``: 모든 요소의 양옆에 균등한 여백을 부여 (요소와 요소 사이 여백은 양 끝 여백의 2배가 됨)  
- ``space-evenly``: 요소와 요소 사이, 그리고 양 끝의 모든 여백을 완전히 동일하게 분배  

### 3.3 align-items  

- `stretch`: 자식 요소의 높이(또는 너비)가 지정되지 않은 경우, 교차축 방향으로 컨테이너 채우듯 늘어남  
- `flex-start`: 교차축의 시작점에 요소들을 정렬  
- `center`: 교차축의 중앙에 요소들을 정렬  
- `flex-end`: 교차축의 끝점에 요소들을 정렬  
- `baseline`: 자식 요소들의 높이나 크기가 서로 다르더라도, 내부 텍스트의 첫 번째 줄 기준선(글자 밑선)을 맞춰 정렬

## 4. CSS Grid

- `display: grid`: 부모 요소에 지정하여 자식 요소들을 가로, 세로의 2차원 바둑판 형태로 배치  

- `Flexbox`는 1차원 정렬에 특화, `Grid`는 행과 열을 동시에 제어하기에 적합  

- `grid-template-columns`: 열의 개수와 너비를 지정  
    - `repeat(4, 1fr)`: 동일한 비율(`1fr`)의 열을 4개 생성  

- `grid-template-rows`: 행의 개수와 너비를 지정하지만, 생략이 가능하며 생략하면 내용에 맞춰 자동으로 정해짐  

- `fr`: 남은 가용 공간을 비율에 따라 유연하게 분할하는 가변 단위

    - `fr`와 `px`을 섞어서 지정도 가능  

- `gap`: 칸과 칸 사이의 간격을 지정
