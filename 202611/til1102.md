## 1. Dockerfile 

- 직접 만든 App(Spring Boot, React)을 Docker Image로 만들려면(`docker build`) Dockerfile이 필요  

- MariaDB처럼 공식 이미지가 있는 것은 그대로 사용, 직접 만든 앱만 Dockerfile 작성이 필요  

### 1-1. 멀티 스테이지 빌드  

- 빌드용 이미지와 실행용 이미지를 분리 → 최종 이미지에는 실행에 필요한 것만 남아 용량 감소  

```dockerfile
# Spring Boot: Maven + JDK로 JAR 빌드 → JRE만으로 실행할 수 있으므로 JDK를 제외 가능
FROM maven:3.9-eclipse-temurin-17 AS build
WORKDIR /app
COPY pom.xml .
RUN mvn dependency:go-offline -B
COPY src ./src
RUN mvn package -DskipTests -B

FROM eclipse-temurin:17-jre-alpine
COPY --from=build /app/target/app.jar app.jar
HEALTHCHECK CMD wget -qO- http://localhost:8080/actuator/health || exit 1
ENTRYPOINT ["java", "-jar", "app.jar"]
```

## 2. Docker Compose  

### 2-1. 사용 이유  

- 여러 개의 컨테이너를 한 번에 관리 → `docker compose up -d` 한 번으로 실행 가능

- 컨테이너 간 통신을 위한 Network 자동 설정 → 서비스 이름이 곧 접속 주소(`mariadb`, `app`)  

- Container 간 의존관계 설정이 용이 → `depends_on` + `condition: service_healthy`  

### 2-2. yml 구조  

```yaml
name: boot-flyway          # 프로젝트 이름 → 컨테이너·네트워크·볼륨 이름 앞에 붙음
services:                  # 실행할 컨테이너 목록
  mariadb:
    image: mariadb:10.11.18
    env_file: .env
    volumes:
      - mariadb-data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "healthcheck.sh", "--connect", "--innodb_initialized"]
  app:
    image: ${DOCKERHUB_USERNAME}/boot-flyway-app:${APP_TAG:-latest}
    environment:
      DB_HOST: mariadb
    depends_on:
      mariadb: { condition: service_healthy }
volumes:
  mariadb-data:
# networks 생략 → boot-flyway_default 네트워크 자동 생성
```

| 키 | 의미 |
| :--- | :--- |
| `image` / `build` | 사용할 이미지 / Dockerfile로 빌드 |
| `env_file` / `environment` | 환경 변수 전달 |
| `ports` | 호스트 포트 ↔ 컨테이너 포트 |
| `volumes` | 볼륨 마운트 |
| `depends_on` | 실행 순서 제어 |
| `restart` | 재시작 정책 |

- `depends_on: [mariadb]`만 쓰면 컨테이너 시작만 기다림 → DB 준비 완료까지 기다리려면 `service_healthy`

## 3. GitHub Actions  

- GitHub 저장소에 내장된 CI/CD 자동화 도구  

- push, PR 같은 이벤트가 발생하면 GitHub의 가상 머신(Runner)에서 정해진 작업 자동 실행  

- CI: 코드가 합쳐질 때마다 자동 빌드·테스트

- CD: 배포 가능한 결과물(이미지) 생성·배포 자동화

## 4. 3Tier 구성의 EC2 배포 과정  

```
내 PC ──git push──▶ GitHub Actions ──▶ Docker Hub (app, web 이미지)
                                          │ docker compose pull
                                          ▼
EC2 ───────────────────────────────────────────────────────────
│ 인터넷 ──80──▶ web(nginx) ──/api──▶ app:8080 ──▶ mariadb:3306
│              Presentation         Application      Data (볼륨)
└───────────────────────────────────────────────────────────────
```
