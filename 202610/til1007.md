## 1. LLM과 LCEL(Langchain Expression Language) 

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()   # .env의 OPENAI_API_KEY를 환경 변수로 등록
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

prompt = PromptTemplate.from_template("{input}에 대해 쉽게 설명해주세요.")
chain = prompt | llm | StrOutputParser()
result = chain.invoke({"input": "인공지능 모델의 학습 원리"})    # str
```

- **LCEL**: `|`로 연결하면 왼쪽 출력이 오른쪽 입력이 됨 → `dict` → 프롬프트 → `AIMessage` → `str`  

- `invoke()`에는 `dictionary`를 넘기고, 키는 템플릿의 `{변수명}`과 같아야 함 (다르면 `KeyError`)  

- `StrOutputParser()`가 없으면 결과가 `AIMessage` → 본문은 `result.content` 
- `strOutputParser`가 chain의 마지막에 `result.content`를 `str`로 변환   

- `temperature`: 다음 토큰을 고를 때의 무작위성을 정하는 값  

    - LLM은 매번 "다음에 올 토큰"의 확률을 계산해서 하나를 고름 (예: "김치" 다음 → 찌개 92%, 볶음밥 5%, 전 2%)  

    - 값이 낮으면 확률이 가장 높은 토큰만 고르고, 높으면 확률이 낮은 토큰도 뽑힐 수 있게 됨  

    | 값 | 동작 | 어울리는 작업 |
    | :--- | :--- | :--- |
    | `0` | 같은 입력에 거의 같은 답 | 분류, 키워드·정보 추출, JSON 생성 |
    | `0.7` | 자연스럽게 조금씩 다른 답 | 추천, 설명, 요약, 일반 대화 |
    | `1.0` 이상 | 창의적이지만 일관성이 떨어짐 | 아이디어 발산, 이름 짓기 |

    - `0`이어도 **완전히 같은 답이 보장되지는 않음** → 결과를 비교하며 테스트할 때는 `0`으로 두는 편이 편함  

    - 답의 **길이나 정확도**를 조절하는 값이 아님 → 길이는 프롬프트 지시나 `max_tokens`로 조절

## 2. 프롬프트  

### 2-1. `ChatPromptTemplate`

```python
from langchain_core.prompts import ChatPromptTemplate

chat_prompt = ChatPromptTemplate.from_messages([
    ("system", "당신은 {topic} 분야의 전문가입니다."), 
    ("user", "{model_name} 모델의 학습 원리를 설명해 주세요."),  
])
chain = chat_prompt | llm | StrOutputParser()
```

- `(역할, 내용)` 튜플의 리스트, 역할은 `system` / `user`(`human`) / `ai`  

### 2-2. Few-shot 

```python
from langchain_core.prompts import FewShotChatMessagePromptTemplate

examples = [                                        
    {"input": "뉴턴의 운동 법칙을 요약해 주세요.", "output": "### 뉴턴의 운동 법칙\n- **관성**: ..."},
    {"input": "지구의 대기 구성 요소를 알려주세요.", "output": "### 지구 대기의 구성\n- **질소**: ..."},
]

example_prompt = ChatPromptTemplate.from_messages([("human", "{input}"), ("ai", "{output}")])
few_shot_prompt = FewShotChatMessagePromptTemplate(example_prompt=example_prompt, examples=examples)

final_prompt = ChatPromptTemplate.from_messages([
    ("system", "당신은 초등학생도 이해할 수 있게 설명하는 과학 교육자입니다."),
    few_shot_prompt,                                  
    ("human", "{input}"),        
])
chain = final_prompt | llm | StrOutputParser()
```

- `example_prompt`: 예시 dict 하나를 `human`(질문) / `ai`(모범 답안) 메시지 한 쌍으로 바꾸는 틀  

- `few_shot_prompt`: 모든 예시에 `example_prompt`을 적용해 `human → ai → human → ai` 메시지 묶음으로 만듦  

- `final_prompt`: `system`(역할) + 예시 묶음 + 마지막 `human`(실제 질문) 순서로 합침  

    - 모델은 예시를 **앞에서 주고받은 대화**로 보고, 실제 질문에도 같은 형식으로 답함  

- 문자열형 `FewShotPromptTemplate`은 `examples`, `example_prompt`(`PromptTemplate`), `prefix`(지시문), `suffix`(실제 질문), `input_variables`로 만듦

## 3. Multi Chain 

```python
from langchain_core.runnables import RunnablePassthrough

prompt1 = ChatPromptTemplate.from_messages([
    ("system", "당신은 영화 평론가입니다."),
    ("user", "{genre} 장르의 영화를 한 편만, 제목만 알려주세요."),
])
prompt2 = ChatPromptTemplate.from_messages([
    ("system", "당신은 영화 평론가입니다."),
    ("user", "{movie} 영화의 감독, 캐스팅, 줄거리를 알려 주세요."),
])

chain1 = prompt1 | llm | StrOutputParser()                 # 장르 → 영화 제목
chain2 = {"movie": chain1} | prompt2 | llm | StrOutputParser()   # 제목 → 영화 정보
response = chain2.invoke({"genre": "Drama"})
```

- `prompt2`는 dict를 받으므로 chain1의 문자열을 `{"movie": chain1}`으로 감쌈 → 키는 `prompt2`의 `{movie}`와 같아야 함  

- `chain1.invoke()`와 `chain2.invoke()`를 따로 부르면 chain1이 **두 번 실행**돼서 출력한 제목과 2단계 내용이 다를 수 있음  

- 두 단계 결과를 모두 받으려면 `assign()`으로 기존 dict에 키를 추가 (chain1은 한 번만 실행)  

    ```python
    full_chain = {"movie": chain1} | RunnablePassthrough.assign(info=prompt2 | llm | StrOutputParser())
    result = full_chain.invoke({"genre": "Drama"})   # result["movie"], result["info"]
    ```
