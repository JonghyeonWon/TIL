- 타입 변환: 타입을 다른 타입으로 변환하는 것  
- 클래스의 타입 변환은 상속 관계에 있는 클래스 사이에서 발생  
---
- 자동 타입 변환
```java
부모타입 변수 = 자식타입객체; // 자식 -> 부모로 자동 타입 변환
Animal animal = new Cat();
```
- 부모 타입으로 자동 타입 변환된 이후에는 부모 클래스에 선언된 필드와 메소드만 접근이 가능  
- 자식 클래스에서 오버라이딩된 메서드가 있다면 부모 메서드 대신 오버라이딩된 메서드가 호출됨  
---
- 강제 타입 변환  
```java
자식타입 변수 = (자식 타입) 부모타입 객체;
Parent parent = new Child();    // 자동 타입 변환
Child child = (Child) parent;   // 강제 타입 변환  
```
- 자식 타입에 선언된 필드와 메소드를 꼭 사용해야 한다면 강제 타입 변환을 통해 다시 자식 타입으로 변환해야함  
---
- 다형성: 사용 방법은 동일하지만 실행 결과가 다양하게 나오는 성질  
```java
public class Tire {
    // 메서드 선언
    public void roll() {
        sout("회전합니다.");
    }
}
```
```java
public class HankookTire extends Tire {
    // 메서드 재정의(오버라이딩)
    @Override
    public void roll() {
        sout("한국타이어가 회전합니다.");
    }
}
```
```java
public static void main(String[] args) {
    Car myCar = new Car();
    myCar.tire = new Tire();
    myCar.run();    // 회전합니다.
    myCar.tire = new HankookTire();
    myCar.run();    // 한국 타이어가 회전합니다.
}
```

- 객체 타입 확인 -> `instanceof` 연산자 사용
```java
boolean result = 객체 instanceof 타입;
```
---
- 추상 클래스: 실체 클래스들의 공통적인 필드나 메서드를 추출해서 선언한 클래스  
- 실제 클래스의 부모 역할을 하므로 실체 클래스는 추상 클래스를 상속해서 공통적인 필드나 메서드를 물려받을 수 없음  
- `new` 연산자를 사용해서 객체를 직접 생성할 수 없음  
- `extends` 뒤에만 올 수 있음  
```java
// 추상 클래스 선언
public abstract class 클래스명 {

}
```
- 추상 메서드
```java
접근 제어자 abstract 리턴타입 메서드명(매개변수);
```
- 추상 메서드의 선언부만 동일하고 실행 내용은 자식 클래스마다 다를 수 있음
