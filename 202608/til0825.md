### 0825 TIL
---
**접근 제어자**: 객체의 필드를 외부에서 접근/변경하거나 메서드를 노출하지 않도록 유지하기 위해 사용  

`public` > `protected` > `default` > `private`

`public`: 제한 범위가 없고, 클래스, 필드, 생성자, 메서드 모두 제한 가능  
`protected`: 같은 패키지이거나, 자식 객체만 사용 가능하며, 필드, 생성자, 메서드만 제한 가능  
`default`: 같은 패키지로 제한하며, 클래스, 필드, 생성자, 메서드 모두 제한 가능  
`private`: 같은 객체 내부로 제한하며, 필드, 생성자, 메서드만 제한 가능  

---
- **상속(inheritance)**: 부모 클래스의 필드, 메서드를 자식 클래스에게 물려주는 행위  

- 부모 클래스  
```java
public class A {
    int field1;
    void method1{   };
}
```
- 자식 클래스: 선언할 때 상속받을 부모 클래스를 `extends` 뒤에 기술  
- 자바는 다중 상속을 허용하지 않음  
```java
public class B extends A {
    String field2;
    void method2{   };
}
```
---
- 자바에서는 자식 객체를 생성하면 부모 객체가 먼저 생성된 다음 자식 객체가 생성됨  
- 모든 객체는 생성자를 호출해야만 생성되지만, 부모 생성자는 기본적으로 자식 생성자의 맨 첫 줄에 숨겨져 있음  
```java
public 자식클래스(...) {
    super();     // 숨겨져 있음
    ...
}
```
- `super()`는 컴파일 과정에서 자동으로 추가되는데, 이는 부모의 기본 생성자를 호출함  
- 부모 클래스에 기본 생성자가 없다면 자식 생성자 선언에서 컴파일 에러 발생  
- 부모 클래스에 매개변수를 갖는 생성자만 있다면 super() 코드를 직접 작성해야함  
```java
public 자식클래스(...) {
    super(매개값, ...); // 직접 작성 필요
    ...
}
```
---
- **오버라이딩(overriding)**: 상속된 메서드를 자식 클래스에서 재정의 하는 것  
- 메서드가 오버라이딩되면 부모 메서드는 숨겨지고, 자식 메서드가 우선적으로 사용됨  
- 부모 메서드의 선언부와 동일해야함  
- `@Override`: 메서드 오버라이딩 되었음을 의미하고, 컴파일 시 정확히 오버라이딩이 되었는지 체크해주는 역할(생략 가능)  
- **오버로딩(overloading)**: 메서드 이름은 같지만, 매개변수의 타입, 개수, 순서가 다른 메서드를 여러 개 선언하는 것
